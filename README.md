# 숲의 불씨 · 정령 수호대

설치 없이 친구들과 플레이하는 디펜스 테스트 빌드입니다. GitHub Pages용 정적 HTML/CSS/JS입니다.

## 플레이
- 여섯 정령이 자동 공격합니다. 원형 발판을 드래그하거나 좌우 버튼으로 공격 방향을 바꿉니다.
- 연쇄 번개, 범위 포격, 감속·쇄빙, 약화 표식, 밀치기가 함께 작동합니다.
- 지원 요청: 24초 대기 후 범위 폭격. 처치로 기운을 모아 불씨 폭주를 사용합니다.
- 12개 웨이브와 최종 보스. 중간 강화 5회. 키보드 ← →, 1 지원, 2 폭주, P 일시정지.
- 패배 시 한 판 1회 부활. 현재 공개 빌드의 광고는 명확하게 표시된 4초짜리 테스트 화면입니다. 실제 광고·수익은 발생하지 않습니다.

## 테스트 범위와 저장
점수·최고 웨이브·누적 기록은 해당 브라우저의 localStorage에 저장됩니다. 로그인, 서버 동기화, 공용 랭킹, 결제는 없습니다. 브라우저 데이터를 지우면 기록도 지워집니다. 전투 도중 새로고침하면 진행 중인 전투는 유지되지 않습니다.

이 빌드는 출시 완료 서비스가 아닙니다. 단일 포즈 원화에 애니메이션 변형을 적용한 프로토타입이며 밸런스·실기기·접근성 추가 테스트가 필요합니다. 이미지는 생성 도구로 제작한 원본 시안에서 추출했습니다.

## 앱인토스 연결
integration/toss-rewarded.mjs는 앱인토스 Web Framework를 설치한 별도 빌드 환경에 연결하는 어댑터입니다. 정적 Pages 페이지에서 이 파일을 불러오거나 실제 광고를 표시하지 않습니다. 운영 전 콘솔 광고 그룹, 최신 SDK, 등급분류, 약관/개인정보/고객지원, 심사 및 권리 검토가 필요합니다. 공식 SDK의 userEarnedReward 이벤트와 종료 이벤트를 확인해야 부활이 승인되며, 닫기만으로 지급하지 않습니다.

공개 테스트는 EMBER_CONFIG.adMode='demo'입니다. live에서 SDK가 없으면 실패 처리하며 가짜 광고로 대체하지 않습니다.
